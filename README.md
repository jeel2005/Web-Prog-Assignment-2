# Personal Portfolio Website
A personal portfolio website built using Express.js and EJS. It includes information about me, my projects, and a contact page. The website was created with npx express-generator --view=ejs portfolio

## Features
- Home page
- About Me page
- Projects page displaying projects using an array of objects
- Contact page with JavaScript form validation
- Reusable header and footer using EJS partials
- Responsive layout using Bootstrap 5

## Technologies Used
- Node.js
- Express.js
- EJS
- JavaScript
- HTML and CSS
- Bootstrap 5
- Font Awesome

## Run Locally

1. Install the dependencies:

   `npm install`

2. Start the application:

   `npm start`

3. Open your browser and visit:

   http://localhost:3000

## Project Structure
- `bin/` - Server startup file
- `routes/` - Website page routes
- `views/` - EJS pages and reusable partials
- `public/` - CSS, JavaScript and images
- `app.js` - Main Express application configuration
